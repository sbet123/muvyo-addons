# TG 自动签到

用 Muvyo 已登录的 Telegram 账号，按你设定的时间，把指定内容发给指定机器人（例如 `/checkin`），完成每日签到。

## 怎么用

1. 安装时允许「使用 Muvyo 的 Telegram 机器人」；插件会列出它能发消息的机器人清单（`yingshiziyuan_bot`）。
2. 在插件设置里填 **任务 1–5**：聊天对象已预填 `yingshiziyuan_bot`，只填名称和聊天内容即可。
3. 打开「定时任务」，给需要执行的每条任务设定每天的时刻。没填聊天内容的任务会自动跳过。
4. 签到结果会出现在「签到」通知和设置页顶部；插件代码不记录消息内容。

## 限制（平台规则，不是本插件加的）

- 最多 5 条任务；任务本身写在插件清单里，安装后不能新增第 6 条。
- 只能给插件清单 `telegram_bots` 里列出的机器人发消息，最多 5 个；想换机器人要作者改清单后重新签名发布。
- 只能发文字，不能点按钮；每条内容 1–500 字、最多 4 行。
- 每个插件每天最多发 30 条；同一时间只执行一个任务，5 条任务建议错开时刻。
- 需要先在 Muvyo 的「Telegram 账号」里登录，且账号能正常给这些机器人发消息。

## 隐私

消息只通过 Muvyo 的 Telegram 会话发出；Muvyo 日志只记「给 @机器人 发了一条消息」，不记内容。插件不读取你的其它聊天、联系人或成员列表。
