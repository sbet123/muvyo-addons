# 无界签到

每天用 Muvyo 已登录的 Telegram 账号，给 **@boundlesscloud_bot** 发送 `/checkin` 完成签到。

这个机器人的回复是奖励金额/流量 + 下次可签到时间，例如：

```
🎉 签到成功！
💰 余额 +0.03 元
⏱ 下次可签到时间：2026-05-09 00:52
```

会整理成一条签到通知：

```
余额 +0.03 元，下次可签到 2026-05-09 00:52
```

有时奖励是流量：

```
📦 流量 +0.82 GB
```

通知就是 `流量 +0.82 GB，下次可签到 2026-11-09 22:28`。

> 这个机器人没有「积分 / 连续签到」字段，所以通知里不会出现这两项。如果它以后改回「获得积分」「连续签到」的写法，插件也会自动解析并显示。

## 怎么用

1. 安装时允许「使用 Muvyo 的 Telegram 机器人」。
2. 打开插件设置的「定时任务」，把「每日签到」的**自动运行**打开，并按需打开**推送签到结果**。
3. 执行方式可选「每天固定时刻」或「时段内随机」，默认每天一次。
4. 机器人换了签到命令时，在插件设置的「签到命令」里改（默认 `/checkin`）。

## 说明

- 设置页顶部会显示上次签到的时间、余额/流量奖励、下次可签到时间和结果。
- 机器人没有回复时只记为「结果未知」，不会当成失败重试，避免重复签到。
- 只发文字，不点按钮；每天最多 30 条消息，本插件每天只用 1 条。
- 需要先在 Muvyo「Telegram 账号」里登录。
