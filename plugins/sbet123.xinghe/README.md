# 星河

每天用 Muvyo 已登录的 Telegram 账号，给 **@yingshiziyuan_bot** 发送 `/sign` 完成签到。

机器人回复例如：

```
今日已签到
连续天数：6
今日积分：+5
当前积分：282
```

会被整理成一条签到通知：`获得积分 5，连续签到 6 天，当前积分 282`。机器人不返回连续天数时只显示两项（`获得积分 5，当前积分 282`）。「连续天数」「连续签到」两种叫法都能识别。

## 怎么用

1. 安装时允许「使用 Muvyo 的 Telegram 机器人」。
2. 打开插件设置的「定时任务」，把「每日签到」的**自动运行**打开，并按需打开**推送签到结果**。
3. 执行方式可选「每天固定时刻」或「时段内随机」（例如 08:00–10:00），默认每天一次。
4. 机器人换了签到命令时，在插件设置的「签到命令」里改（默认 `/sign`）。
5. 机器人回复慢时，把「等待回复（秒）」调到 30（默认 30，平台上限）。Muvyo 的机器人接口是「发送 + 等待」一次完成，没有单独的延后读取，所以只能把等待拉长。

## 说明

- 设置页顶部会显示上次签到的时间、获得积分、当前积分（有连续签到时也会显示天数）。
- 机器人没有回复时只记为「结果未知」，不会当成失败重试，避免重复签到。
- 只发文字，不点按钮；每天最多 30 条消息，本插件每天只用 1 条。
- 需要先在 Muvyo「Telegram 账号」里登录。
